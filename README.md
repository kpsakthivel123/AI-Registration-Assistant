# Registration Assistant — AI-SS-001

## Internship Task
**Task:** Registration Assistant  
**Task ID:** AI-SS-001  
**Category:** AI & Data Science

## Features
- Student academic profile / eligibility checker
- Course explorer with six courses
- Rule-based AI registration assistant
- Course recommendations based on qualification and percentage
- Registration request form
- Responsive, app-like dashboard UI
- No external API or paid service required

## Technology
- HTML5
- CSS3
- JavaScript (ES6)
- Client-side rule-based AI / recommendation logic

## How to Run
1. Extract the ZIP file.
2. Open the project folder.
3. Double-click `index.html`.
4. The application runs directly in a browser; internet is not required.

## Demo Flow
1. Enter student name, qualification and percentage.
2. Click **Check My Eligibility**.
3. Explore recommended courses.
4. Open the **AI Registration Assistant** and ask questions.
5. Select a course.
6. Submit the demo registration request.

## Note
This is a front-end internship demonstration. The AI assistant uses a lightweight local intent/keyword matching engine so it works offline. A production version could connect the same interface to a Python/Flask backend, database and an approved AI API.
